알아 두세요
사용자 권한(최고 관리자, 각 부서 팀장 등)에 따라 보이는 버튼과 사용할 수 있는 기능이 다를 수 있습니다. 이 매뉴얼의 화면은 최고 관리자 계정 기준이며, 출장자 관리 화면은 가상의 시험 데이터로 만들었습니다.
CHAPTER 1

시작하기

(주)TW 스마트 프로젝트 관리 시스템은 프로젝트 일정, 공수, 출장자 배정, 이슈, 공사일보, 견적, Vision SPC 분석을 한 곳에서 관리하는 웹 애플리케이션입니다. 이 매뉴얼은 처음 쓰는 사람도 화면을 보며 따라 할 수 있도록 기능별 사용 순서와 주의할 점을 함께 적었습니다.

1. 시작하기

1-1. 로그인

회사 이메일 계정(@twgroup.co.kr)으로 로그인합니다.

  1. 이메일과 비밀번호를 입력하고 [로그인]을 누릅니다.
  2. 처음 사용하는 경우 [회원가입 신청]에서 이름과 소속팀을 포함해 신청합니다. 이름과 소속팀은 필수 항목입니다.
  3. 비밀번호를 잊은 경우 [비밀번호 재설정]을 누릅니다.
  4. 오른쪽 위의 해/달 모양 버튼으로 라이트/다크 화면을 바꿀 수 있습니다.
1. 시작하기

1-2. 회원가입 신청

처음 사용하는 경우 로그인 화면의 [회원가입 신청]으로 계정을 신청합니다.

  1. 회사 이메일, 이름, 소속팀, 비밀번호를 입력하고 [회원가입 신청]을 누릅니다. 이름과 소속팀은 필수입니다.
  2. 가입 직후에는 조회 위주의 기본 권한이 부여됩니다. 더 많은 기능이 필요하면 시스템 관리자에게 권한 변경을 요청하세요.
  3. 이미 계정이 있으면 [로그인]을 눌러 로그인 화면으로 돌아갑니다.
1. 시작하기

1-3. 비밀번호 찾기/재설정

비밀번호를 잊었을 때 로그인 화면의 [비밀번호 재설정]을 누릅니다.

  1. 가입한 회사 이메일을 입력하고 [재설정 링크 메일 발송]을 누르면 메일로 재설정 링크가 전송됩니다.
  2. 메일의 링크에서 새 비밀번호를 설정한 뒤 다시 로그인합니다.
1. 시작하기

1-4. 화면 구성

로그인하면 프로젝트 일정 화면이 열립니다. 모든 화면의 위쪽 구성은 같습니다.

  1. 상단 메뉴: 프로젝트 일정 / 공수 통합 관리 / 출장자 관리 / 이슈 통합 관리 / 공사일보 통합 관리 / 견적 조회 / Vision SPC를 전환합니다. 권한이 없는 메뉴는 누르면 안내 창이 나옵니다.
  2. 고객사 줄: SK on, Samsung SDI, Hyundai 중 볼 고객사를 고릅니다. 이름 옆 숫자는 등록된 프로젝트 수입니다.
  3. 조회 연도 줄: 당해년도, 최근 2개년, 최근 3개년, 전체 연도 또는 연도별 버튼으로 조회 범위를 정합니다. 오른쪽에 현재 범위와 프로젝트 건수가 표시됩니다.
  4. 예외: 출장자 관리 화면은 모든 고객사의 프로젝트를 한꺼번에 다루므로 고객사 줄과 조회 연도 줄이 숨겨집니다.
  5. 화면 머리말과 하위 메뉴: 화면 제목 아래의 밑줄 탭으로 세부 기능을 바꿉니다.
  6. 오른쪽 위 사용자 메뉴: 이름과 권한이 표시되며, 누르면 아래 메뉴가 열립니다.
1. 시작하기

1-5. 사용자 메뉴

오른쪽 위 이름 영역을 누르면 계정 관련 메뉴가 열립니다.

  1. 비밀번호 변경: 내 비밀번호를 바꿉니다.
  2. 캐시 새로고침: 화면이 최신 내용으로 바뀌지 않을 때 누릅니다.
  3. 로그아웃: 시스템에서 나갑니다.
1. 시작하기

1-6. 비밀번호 변경

사용자 메뉴의 [비밀번호 변경]을 누르면 변경 창이 열립니다.

  1. 새 비밀번호와 새 비밀번호 확인을 같게 입력하고 [비밀번호 변경 저장]을 누릅니다. 입력칸 옆 [보기]로 입력 내용을 확인할 수 있습니다.
  2. [취소]를 누르면 변경하지 않고 닫습니다.
1. 시작하기

1-7. 라이트/다크 화면 전환

오른쪽 위 해/달 모양 버튼으로 화면 색상을 바꿉니다.

  1. 기본은 어두운 화면(다크)이고, 버튼을 누르면 밝은 화면(라이트)으로 바뀝니다. 다시 누르면 돌아옵니다.
  2. 이 매뉴얼의 대부분 화면은 다크 모드 기준입니다.
1. 시작하기

1-8. 표 붙여넣기와 파일 첨부

엑셀 데이터를 시스템에 넣는 방법은 어느 화면이든 같습니다. 회사 보안(DRM) 때문에 파일 첨부가 안 되는 문서가 많아서 표 붙여넣기가 기본 방법이고, 파일 첨부는 옆의 보조 버튼입니다.

  1. 엑셀에서 필요한 표(머리글 포함)를 드래그해 복사합니다.
  2. 화면의 색이 있는 큰 점선 칸(Ctrl V 키 그림이 보이는 칸)을 마우스로 한 번 누르고 Ctrl+V를 누릅니다. 마우스 오른쪽 버튼을 눌러 [붙여넣기]를 골라도 됩니다.
  3. 붙여넣은 내용은 바로 저장되지 않고 미리보기로 먼저 나옵니다. 내용과 검증 결과를 확인한 뒤 저장 버튼을 누릅니다.
  4. 파일 첨부가 되는 문서라면 점선 칸 옆의 [파일 첨부 (Excel)]를 눌러 엑셀 파일을 올려도 결과는 같습니다. 파일은 내 브라우저에서만 읽고 서버에 올리지 않습니다.
  5. 프로젝트 미선택이나 권한 부족으로 칸이 비활성이면 칸 안에 이유가 적혀 있습니다. 그 안내대로 먼저 프로젝트를 고르거나 권한을 확인하세요.
  6. 사용하는 화면: 프로젝트 일정(Master Schedule), 공사일보(작업표·공수표), 견적 조회(견적서·상세 리스트), Vision SPC(검사 데이터), 출장자 관리(팀원 명단).
붙여넣기가 안 될 때
① 점선 칸을 먼저 한 번 눌러 커서가 들어갔는지 확인하세요. ② 표가 아니라 그림으로 복사되었다면 엑셀 셀을 다시 드래그해 복사하세요. ③ 그래도 안 되면 파일 첨부를 쓰거나 9장의 해결 방법을 확인하세요.
CHAPTER 2

프로젝트 일정

선택한 고객사의 마스터 스케줄, 마일스톤 간트 차트, 공수 현황을 관리합니다. 위쪽 [PPT 종합 보고서 내보내기]로 보고서를 만들 수 있고, [전체 펼치기]/[전체 접기]로 모든 구역을 한 번에 열고 닫을 수 있습니다.

2. 프로젝트 일정

2-1. 전체 표시

프로젝트 등록부터 목록까지 모든 구역을 한 화면에 이어서 보여 줍니다.

  1. 아래로 내려가며 등록 → 필터 → 간트차트 → 달력 → 목록을 차례로 확인합니다.
  2. 각 구역 제목 옆의 [접기]로 필요 없는 구역을 접을 수 있습니다.
2. 프로젝트 일정

2-2. 프로젝트 등록/수정

새 프로젝트를 직접 입력하거나 Master Schedule 엑셀로 한 번에 등록합니다.

  1. 엑셀로 등록: [양식 다운로드 받기]로 양식을 받아 작성한 뒤, 표를 복사하고 점선 칸을 클릭해 Ctrl+V 하거나 [파일 첨부 (Excel)]로 올립니다. 공수가 포함되면 공수 통합 관리에 자동 반영됩니다.
  2. 직접 입력: 고객사, Site, 프로젝트명은 필수(*)입니다. 제조번호, Line, 시작일, 종료일, 상태, 담당자(소장·설계·설비기술·제어·비전)를 입력합니다.
  3. [Site 관리], [담당자 관리]에서 Site와 담당자 목록을 편집할 수 있습니다.
  4. [마일스톤 기준 상태 자동 계산], [일정 기준 진행률 자동 계산]을 켜면 마일스톤 날짜로 상태와 진행률이 자동 계산됩니다.
  5. 마일스톤은 [+ 마일스톤 추가]로 단계명과 기간을 넣고, 마지막에 [프로젝트 추가]를 누릅니다.
  6. Master Schedule 엑셀이 없는 프로젝트는 같은 화면의 [부서별 공수 직접 등록]으로 부서별 계획 인원을 기간별로 적을 수 있습니다(2-11 참고).
2. 프로젝트 일정

2-3. Site 관리

[프로젝트 등록/수정] 화면의 [Site 관리] 버튼으로 해당 고객사의 Site 목록을 관리합니다.

  1. 위쪽 입력칸에 새 Site 이름을 적고 [추가]를 누르면 목록에 추가됩니다.
  2. 삭제하려면 목록의 Site를 우클릭합니다. 이미 프로젝트에 쓰이는 Site인지 확인한 뒤 삭제하세요.
  3. 오른쪽 위 [×]로 창을 닫습니다. 이 기능은 권한이 있는 사용자에게만 열립니다.
2. 프로젝트 일정

2-4. 담당자 관리

[담당자 관리] 버튼으로 부서별 담당자 목록을 관리합니다.

  1. 부서(소장, 설계, 설비기술 등)를 고르고 이름을 입력해 [추가]합니다. 여기 등록한 이름이 프로젝트 등록 화면의 담당자 선택 목록에 나타납니다.
  2. 설비기술 아래에는 기구, 비전, 제어, 전장 등 세부 구분이 있고 외주 인원도 구분해 등록합니다.
  3. 목록에서 항목을 우클릭해 삭제합니다.
2. 프로젝트 일정

2-5. 일정 조회 필터

연도, Site, 담당자 기준으로 프로젝트를 좁혀 봅니다.

  1. 연도·Site·담당자를 고르면 간트차트와 목록에 바로 반영됩니다.
  2. [필터 초기화]로 조건을 모두 지웁니다.
2. 프로젝트 일정

2-6. 프로젝트 간트차트

프로젝트별 일정을 막대로 보여 주는 차트입니다. 붉은 선은 오늘(TODAY)입니다.

  1. [공사 일정 기준]과 [전체 프로젝트 일정 기준] 중 표시 기준을 고릅니다.
  2. 진행 기간 설정 칸이나 [이번 달], [다음 달], [이번 분기], [올해 전체] 버튼으로 보는 기간을 바꿉니다.
  3. 막대 오른쪽의 퍼센트는 공사 진행률입니다.
2. 프로젝트 일정

2-7. 프로젝트 일정 달력

월 달력에 공사 일정과 일별 투입 인원을 함께 표시합니다.

  1. [공사일정]과 [전체 프로젝트 일정] 중 무엇을 표시할지 고릅니다.
  2. 연속 막대를 누르면 프로젝트 상세 정보가 열립니다.

2-8. 프로젝트 목록

조회 범위의 모든 프로젝트를 목록으로 보고, 진행률과 상태를 확인합니다.

  1. [전체/진행중/완료/지연] 버튼으로 상태별로 걸러 봅니다. 검색칸으로 이름·Site·Line을 검색합니다.

  1. 위쪽 요약: 총 공수(Total Man-day), 일일 최대 투입 인원(Daily Peak), 투입 일수.

2. 프로젝트 일정

2-11. 부서별 공수 직접 등록

Master Schedule 엑셀이 없는 프로젝트라도 기간과 부서별 인원만 적으면 계획 공수로 등록됩니다. 등록한 값은 공수 통합 관리, 출장자 관리의 필요 인원, 보고서·엑셀 내보내기에 그대로 반영됩니다.

  1. 프로젝트 등록/수정 화면에서 진행률 설정 아래의 [부서별 공수 직접 등록] 칸을 찾습니다.
  2. [+ 구간 추가]를 누르고 구간마다 부서(기구·비전·제어·전장·소장, 기구/비전/제어/전장 외주), 시작일, 종료일, 인원(1 이상)을 입력합니다. 부서마다 구간을 여러 개 만들 수 있고, 같은 부서의 구간이 겹치면 인원이 합산됩니다.
  3. 일요일은 제외하고(월~토) 하루 인원으로 계산합니다. 칸 아래 합계 M/D(사람×일수)로 바로 확인합니다. 잘못 넣은 구간은 오른쪽 휴지통 버튼으로 지웁니다.
  4. 날짜가 비었거나 종료일이 시작일보다 빠르거나 인원이 0인 줄은 계산에서 빠집니다.
  5. 화면 아래의 [프로젝트 추가](새 프로젝트) 또는 [수정 저장](기존 프로젝트)을 눌러야 반영됩니다. 구간을 모두 지우고 저장하면 공수가 없는 프로젝트가 됩니다.
  6. Master Schedule 공수가 이미 있는 프로젝트에서는 입력칸 대신 안내 문구만 나옵니다. 마스터 공수가 우선이고, 나중에 Master Schedule을 붙여넣으면 직접 등록한 값은 마스터 값으로 대체됩니다.
  7. 이 칸은 프로젝트 정보를 모두 수정할 수 있는 권한(관리자, Grade3)에게만 보입니다.
예시 11월 2일~27일 기구 3명, 11월 9일~27일 비전 2명, 11월 16일~12월 4일 제어 1명을 적으면 부서별 M/D가 자동 계산되어 공수 확인 창과 출장자 관리의 부서 필요 인원에 나타납니다.
CHAPTER 3

공수 통합 관리

프로젝트에 계획된 인력 공수(M/D)를 전사·부서·프로젝트 단위로 모아 보고, 실제 투입 공수와 비교합니다. 프로젝트 일정에 공수를 포함해 등록하거나 프로젝트 수정 화면에서 부서별 공수를 직접 적으면 자동으로 이곳에 반영됩니다.

3. 공수 통합 관리

3-1. 계획공수 조회 조건 및 필터

조회 기준을 정합니다.

  1. [월간 단위 조회]와 [기간 지정 조회] 중 선택합니다. 월간 단위 조회에서는 월 이동 버튼(‹ ›)과 [이번달]로 기준 월을 바꿉니다.
  2. Site 필터와 부서 필터로 범위를 좁히고, 검색칸에서 프로젝트·제조번호로 찾습니다.
  3. [공수 보고서 PPT 다운로드 (n월)]로 선택한 기준의 보고서를 받습니다.
3. 공수 통합 관리

3-2. 기간 지정 조회

[기간 지정 조회]를 선택하면 원하는 기간을 직접 정해 조회합니다.

  1. 조회 기간의 시작일과 종료일을 입력하거나 [1개월], [3개월], [6개월], [전체 기간] 버튼으로 빠르게 지정합니다.

3. 공수 통합 관리

3-3. 전사 요약 및 부서별 현황

선택한 월의 총 공수, 투입 프로젝트 수, 최대 투입 인원과 부서별 편성 현황을 보여 줍니다.

  1. 부서별 카드(기구, 비전, 제어, 전장, 안전, 소장 등)에서 부서별 M/D와 비중을 확인합니다.
3. 공수 통합 관리

3-4. 일별 전사 투입 달력

날짜별 투입 인원을 달력으로 확인합니다.

  1. 달력의 각 날짜에서 그날 투입되는 인원을 확인합니다.
  2. 아래 일별 부서 공수 매트릭스에서 부서별 일별 인원과 월간 합계를 확인합니다.

3-5. 프로젝트별 계획공수 현황

프로젝트별로 월별·부서별 계획 공수를 표로 확인합니다.

  1. 프로젝트 행별로 부서별 M/D와 총 공수를 볼 수 있습니다.
  2. [일일 투입 프로젝트 보기] 체크 옵션으로 해당 기간에 투입이 있는 프로젝트만 표시합니다.

CHAPTER 4

출장자 관리

프로젝트별로 필요한 부서 인원(계획 공수)에 맞춰 출장자를 배정하고, 부서별 인원이 언제 어디에 있는지 한눈에 봅니다. 프로젝트 일정에 등록된 프로젝트와 계획 공수를 그대로 가져와 쓰므로 프로젝트를 따로 등록하지 않습니다. 이 장의 화면은 가상의 시험 데이터(이름·프로젝트)로 만들었습니다.

4. 출장자 관리

4-1. 화면 구성과 사용 권한

상단 메뉴의 [출장자 관리]를 누르면 열립니다. 네 개의 탭과 오른쪽 위 공통 버튼으로 구성됩니다.

  1. 프로젝트 출장자 배정: 프로젝트를 고르고 부서별 칸에 출장자를 넣습니다(4-2~4-8).
  2. 부서 인원 현황: 오늘(또는 고른 날) 부서 인원이 본사·출장·외부·부재 중 어디에 있는지 봅니다(4-9~4-11).
  3. 팀원 관리: 출장자로 배정할 인원 명단을 등록·수정합니다(4-13~4-14).
  4. 종합·확인 사항: 부족·경고와 부서별 주차 종합표를 봅니다(4-15).
  5. 오른쪽 위 [일 단위]/[주 단위]는 모든 탭의 시간 칸을 하루 또는 한 주로 바꿉니다. 고른 값은 이 브라우저에 기억됩니다. [새로고침]은 최신 데이터를 다시 불러오고, [종합 엑셀]은 4-17, 그 아래의 작업 기록 카드는 4-19를 참고하세요.
  6. 다른 사람이 고친 내용은 창으로 돌아올 때(1분 이상 지났으면) 자동으로 다시 읽어 오지만, 바로 확인하려면 [새로고침]을 누릅니다.
  7. 권한: 조회는 관리자·Grade3·Grade2.5·Grade2, 배정·인원·일정 수정은 관리자·Grade3·Grade2.5입니다. Grade2는 위 그림처럼 보기 전용 안내 띠가 나오고 수정 창이 열리지 않습니다. Grade1은 출장자 관리를 쓸 수 없습니다. [종합 엑셀] 내려받기는 관리자·Grade3·Grade2.5만 쓸 수 있습니다.
출장자 관리는 고객사와 연도에 상관없이 전체 프로젝트를 보여 줍니다. 고객사를 통합해 인원을 운영하기 때문입니다.
4. 출장자 관리

4-2. 배정이 필요한 프로젝트 찾기

화면 맨 위의 붉은 띠가 아직 출장자가 배정되지 않았거나 인원이 부족한 프로젝트를 알려 줍니다.

  1. 붉은 띠는 평소 한 줄로 접혀 있고 "출장자 배정이 필요한 프로젝트 N건 · 인원 부족 M건"만 보입니다. [펼쳐서 보기]를 누르면 프로젝트가 작은 칩으로 나열됩니다. 칩을 누르면 그 프로젝트가 열립니다.
  2. 칩의 상태: 미배정(아무도 배정되지 않음)이 먼저, 부족(일부 부서 인원 부족)이 뒤에 나옵니다. 부서 이름이 함께 표시됩니다.
  3. 계획 공수가 아직 등록되지 않은 프로젝트는 필요한 인원을 알 수 없으므로 이 띠에 올라오지 않습니다.
  4. 완료 시점(종료일)이 오늘보다 앞선 프로젝트는 기본으로 숨겨집니다(4-3 참고).
4. 출장자 관리

4-3. 프로젝트 고르기와 검색

프로젝트 선택 상자를 눌러 배정할 프로젝트를 고릅니다.

  1. 위쪽 검색칸에 프로젝트 이름·Site·라인·제조번호를 입력해 찾습니다.
  2. 고객사/Site/상태 선택으로 목록을 좁힐 수 있습니다. 상태는 배정 필요, 인원 부족, 배정 완료, 공수 없음 중에서 고릅니다.
  3. [완료 시점이 지난 프로젝트도 보기]를 체크하면 이미 끝난 프로젝트도 목록에 나옵니다. 기본은 숨김입니다.
  4. 각 줄 오른쪽 배지가 그 프로젝트의 현재 상태입니다. Esc 키나 바깥을 누르면 목록이 닫힙니다.
4. 출장자 관리

4-4. 프로젝트 출장자 배정 화면 읽기

프로젝트를 고르면 부서별 계획 인원과 배정 현황이 한 표에 나옵니다.

  1. 제목 줄: 프로젝트명, 고객사·Site·라인·기간, 상태 배지(진행중, 인원 부족, 배정 필요 등)가 나옵니다. HSBMA·SKBA·SKOT 같은 미국 사이트이면 "미국 사이트 · B1 확인" 표시가 붙습니다(4-16 참고).
  2. 부서 카드(기구·비전·제어·전장·PM): 큰 숫자가 지금 배정된 인원, 뒤가 필요한 인원입니다. 아래 "앞으로 N주 부족"이 아직 모자란 기간입니다. 계획 공수가 없는 부서는 "공수 없음"으로 표시됩니다.
  3. 작업 단계(마일스톤) 띠: 프로젝트 마일스톤이 단계마다 색으로 나오고 위쪽 범례에 날짜가 있습니다. 일정이 겹치는 단계도 줄을 나눠 모두 표시되므로 같은 시기에 어떤 작업이 병행되는지 확인할 수 있습니다.
  4. 부서 블록: 부서마다 필요한 최대 인원만큼 칸(줄)이 만들어집니다. 칸 왼쪽 숫자가 칸 번호, 그 옆이 배정된 사람 이름입니다. 부서 머리의 "3/4" 같은 숫자는 그 시기의 배정/필요 인원이고, 부족하면 붉게 표시됩니다.

4-6. 출장자 배정하기

4-7. 수정·삭제·교대

4-9. 부서 인원 현황

고른 날(또는 고른 주)에 부서 인원이 어디에 있는지 보여 주는 화면입니다. 맨 위의 부서 카드와 아래 부서 상황판으로 구성됩니다.

  1. 부서 카드: "N명 본사 / 총 M"과 "출장·외부·부재·B1" 수입니다. 카드를 누르면 그 부서만 보이고 다시 누르면 전체로 돌아옵니다.
  2. 본사 잔류 칸: 그날 프로젝트나 외부 일정이 없는 인원입니다. 카드에는 이름, B1 표시, 팀·직위, 다음 일정("다음: 프로젝트명 11/2~") 또는 "예정 없음"이 나옵니다. 카드를 누르면 인원 정보 창이 열립니다.
  3. 프로젝트별 칸: 그날 그 프로젝트에 가 있는 인원입니다. 칸 제목 오른쪽 숫자가 배정/필요이고, 부족하면 붉습니다. 인원이 없어도 그날 공수가 있는 프로젝트는 칸이 나와서 부족을 알 수 있습니다.
  4. 외부 칸: 프로젝트가 아닌 일정(고객사 대응·테스트 등)으로 나가 있는 인원이며 간 곳(장소)마다 칸이 나뉩니다. 부재 칸: 휴직·휴가·교육 인원입니다.
  5. 20명을 넘는 부서는 칸이 여러 열로 나뉘어 한 화면에 더 많이 보입니다.

4-10. 날짜 빨리 이동하기

부서 상황판 위의 날짜 줄은 하루씩 넘기는 불편을 줄이도록 단위 이동, 변동일 건너뛰기, 날짜 띠를 함께 제공합니다.

  1. 단위 이동: [-1달][-1주][<][날짜][>][+1주][+1달][오늘]. 날짜 칸을 눌러 달력에서 직접 고를 수도 있습니다. 주 단위 보기에서는 -1주/+1주가 빠지고 달 이동이 4주입니다.
  2. 변동일 버튼([◀ 변동일], [변동일 ▶]): 인원 부족이 처음 시작되거나 인원 수가 바뀌는 날, 출장 시작·종료·외부 일정 시작이 있는 날로 바로 건너뜁니다. 같은 부족이 이어지는 날은 한 번에 지나갑니다.
  3. 날짜 띠: 기준일을 따라다니는 9주 범위입니다. 칸 하나가 하루이며 붉은 칸 = 인원 부족일, 위의 점 = 출장 시작·종료, 테두리 = 오늘, 밑줄 = 선택한 날입니다. 칸을 누르면 그 날로 이동하고 칸에 마우스를 올리면 요약이 나옵니다. 띠 밖으로 나가면 범위가 따라 옮겨 갑니다.
  4. 띠 아래 한 줄 요약(일 단위)은 선택한 날의 부족 내용과 출장 시작·종료를 알려 줍니다.
  5. 부족은 오늘 이후 날짜만 셉니다. 보고 있는 부서 필터(위 부서 카드)를 따릅니다.

4-11. 인원×날짜 표

4-12. 미등록 프로젝트 대응 일정

프로젝트에 배정되지 않았지만 본사 밖에 나가 있는 인원(CS 대응, 고객사 대응, 테스트 등)은 일정으로 적어 둡니다. 그러면 그 기간 본사 가용 인원에서 빠지고, 어디에 가 있는지 보입니다.

4-14. 엑셀로 팀원 명단 일괄 등록·최신화

표 붙여넣기로 팀원 명단을 한 번에 등록하거나 최신화합니다(1-8의 붙여넣기 방법과 같습니다).

  1. 팀원 관리 탭 위의 [빈 양식 내려받기]로 양식을 받습니다. [현재 명단 내려받기]는 지금 명단을 부서별 시트로 나눠 같은 양식으로 내려받으므로, 고쳐서 다시 붙여넣기에 편합니다.
  2. 양식의 머리글은 첫 줄에 있고 열은 부서(분야) · 소속 팀 · 이름 · 직위 · 등급 · B1 비자 · 상태 · 비고입니다. 부서·B1·상태는 목록에서 고릅니다. 이름이 "(예시)"로 시작하는 줄은 붙여넣을 때 건너뜁니다.
  3. [표 붙여넣기로 최신화]를 누르고 점선 칸에 Ctrl+V 하면 기존 명단과 비교한 미리보기가 나옵니다: 새로 추가, 정보 갱신, 팀 이동, 퇴사 후보.
  4. 표에 없는 재직 인원은 퇴사 후보로만 제시되며 기본은 체크가 해제되어 있습니다. 퇴사시킬 사람만 직접 체크합니다.
  5. 표에 열 자체가 없으면 기존 값을 그대로 두고, 열이 있는데 칸이 비어 있으면 값을 비웁니다. B1 비자 현황표 같은 표도 붙여넣을 수 있습니다.
  6. 내용을 확인한 뒤 [저장 (추가 N · 갱신 N …)] 버튼을 누르면 한 번에 저장됩니다.

4-15. 종합·확인 사항

배정이 모자라거나 문제가 있는 곳을 한 화면에서 확인합니다.

  1. 공수 부족 구간: 프로젝트·부서별로 "11/2~11/29 최대 1명 부족"처럼 부족한 기간과 최대 부족 인원이 나옵니다. 항목을 누르면 그 프로젝트의 배정 화면으로 이동합니다. 오늘 이후 부족만 표시됩니다.
  2. 배정 경고: 기간이 겹치는 배정(충돌)이나 B1 비자 미보유 같은 경고 목록이며, 항목을 누르면 해당 프로젝트로 이동합니다.
  3. 부서별 주차 종합: 진행 중인 모든 프로젝트를 합친 표입니다. 부서마다 필요(계획 공수), 배정, 부족(-)/초과(+), 가용 인원이 날짜(또는 주) 칸마다 나옵니다. 부족은 붉은 줄입니다.
  4. 위쪽 [4주 이전/이번 주/4주 이후], 시작 주, 표시 기간으로 보는 범위를 옮깁니다.

4-16. 경고와 판단 기준

시스템이 경고나 부족을 판단하는 기준입니다. 숫자가 이상하게 보일 때 확인하세요.

  1. 충돌: 같은 사람이 같은 기간에 (1) 같은 프로젝트에 겹쳐 배정, (2) 다른 프로젝트에 겹쳐 배정, (3) 휴직·휴가·교육 등 부재와 겹침, (4) 외부 출장(고객사 대응·테스트 등)과 겹치는 경우입니다. 이 중 (1)과 사이트가 다른 (2)는 저장할 수 없고, 같은 사이트의 (2)와 (3)·(4)는 사유를 적으면 저장할 수 있습니다(4-18). 사유가 적힌 겹침은 경고 목록에서 빨간색이 아니라 안내(i)로 바뀝니다.
  2. B1 비자 경고: 프로젝트 Site가 HSBMA·SKBA·SKOT(미국 사이트)일 때만 확인합니다. 다른 해외 사이트는 해당하지 않습니다.
  3. 부족: 날짜마다 (그 프로젝트·부서의 계획 공수) − (그날 배정된 인원)입니다. 부족 인원은 오늘 이후 날짜만 셉니다. 주 단위에서는 그 주의 최대값을 씁니다.
  4. 가용 인원: 재직 중이면서 그 기간에 프로젝트·외부 일정·부재가 없는 인원입니다.
  5. 다른 부서 수정 확인: 팀장(Grade2.5) 계정은 화면 위쪽에서 "내 부서"를 고를 수 있습니다(없으면 계정의 소속 팀에서 추정). 내 부서가 아닌 부서의 배정·인원·특이사항·퇴사·삭제를 저장하려 하면 "내 부서가 아닙니다. 그래도 수정할까요?" 확인 창이 뜨고, 취소하면 저장되지 않습니다. 보는 것에는 제한이 없고 PM·관리자는 경고 없이 수정합니다.
  6. 프로젝트가 안 보일 때: 프로젝트 일정에 등록되어 있는지, 종료일이 오늘보다 앞서 숨겨진 것은 아닌지("완료 시점이 지난 프로젝트도 보기") 확인합니다. 부서 칸이 "공수 없음"이면 프로젝트 일정에서 공수를 등록하거나 직접 등록(2-11)합니다.

4-17. 종합 엑셀 내려받기

프로젝트별 출장자 표를 기존 "동시 여러 PJT 발생 시 대응 방안" 관리장표 양식의 엑셀로 내려받습니다. AI를 쓰지 않고 화면의 배정·인원·일정 데이터를 규칙대로 엑셀로 바꾸며, 브라우저 안에서만 만들어지므로 파일이 서버로 올라가지 않습니다. 관리자·Grade3·Grade2.5만 내려받을 수 있습니다(Grade2는 보기 전용이라 제외).

  1. 오른쪽 위 [종합 엑셀]을 누르고 시작 주와 기간, 옵션(프로젝트를 접은 상태로 시작, 지난 프로젝트 포함)을 정한 뒤 [엑셀 내려받기]를 누릅니다.
  2. 엑셀 안의 시트는 7개입니다. PJT 출장자(프로젝트별 배정표, 주 단위), 종합 현황(부서별 계획 공수 대비 배정·과부족·미배정 칸·본사 가용·외부 일정), 인원별 위치 현황(누가 어느 주에 어디에 있는지), 프로젝트 목차(프로젝트 목록과 이동 링크), 인원 명단, 외부 일정, 작성 안내입니다.
  3. PJT 출장자 시트는 프로젝트마다 머리글 줄 아래에 마일스톤(작업 단계) 띠, 부서별 칸(이름), 부서별 TOTAL, 부서별 특이사항이 이어지고, 맨 아래에 "PJT 별 취합 공수"가 있습니다. 일정이 겹치는 마일스톤은 줄을 나눠 모두 보입니다.
  4. 표시 색: 이름이 들어간 칸은 연한 파랑, 아직 정해지지 않은 자리(분홍 "1")는 연한 분홍, 미국 사이트에서 B1 확인이 안 된 이름은 연한 주황, 같은 주에 두 곳에 배정된 이름은 연한 빨강입니다. 머리글과 마일스톤은 파스텔 톤이며, 글씨는 검정이고 굵게 쓰지 않습니다.
  5. 접고 펼치기: 각 프로젝트 블록 아래의 빈 줄(높이를 키워 두었습니다) 왼쪽 +/− 버튼으로 그 프로젝트만 접고 펼치고, 왼쪽 위 숫자 1·2 버튼으로 전체를 한 번에 접고 펼칩니다.
  6. 수식으로 연결되어 있어, 파일에서 이름 칸을 목록에서 고르거나 바꾸면 TOTAL·취합 공수·종합 현황·인원별 위치 현황이 다시 계산됩니다. 프로젝트 블록을 통째로 복사해 "PJT 별 취합 공수" 위에 붙여도 자동으로 합산됩니다. 왼쪽 가장자리의 작은 글자 H·M·S·T는 합산에 쓰이는 표시이므로 지우지 마세요.
  7. 프로젝트 이름은 줄바꿈 없이 한 줄로 보이고, 칸보다 길면 글씨 크기가 줄어듭니다.
  8. 파일에서 고친 내용은 시스템으로 되돌아오지 않는 내려받기 전용입니다. 시스템의 정본은 항상 화면이므로, 다시 필요하면 최신 상태로 새로 내려받으세요.

4-18. 겹치는 일정과 동일 사이트 일시 예외

한 사람이 같은 기간에 두 곳에 배정되는 일을 막기 위한 규칙입니다. 배정 창(4-6)과 교대 창(4-7)에 똑같이 적용되고, 화면을 거치지 않는 저장도 서버(DB)가 같은 규칙으로 막습니다.

겹치는 상대처리
같은 프로젝트의 다른 배정저장할 수 없음(예외 없음). 후보 목록에서 "배정 불가"로 표시되어 선택되지 않습니다.
사이트가 다른 프로젝트저장할 수 없음. 기간을 나누거나 다른 사람을 고르세요.
같은 사이트의 다른 프로젝트사유를 적으면 저장 가능(동일 사이트 일시 예외).
휴직·휴가·교육 등 부재, 외부 출장(고객사 대응·테스트 등)사유를 적으면 저장 가능. 사유가 없으면 저장되지 않습니다.
  1. 후보 목록에서 "겹침 · 사유 필요"인 사람을 고르면 창 아래에 겹침 사유 (동일 사이트 일시 예외) · 필수 입력칸이 나타납니다. 이유(예: 같은 사이트 두 라인을 오가며 지원)를 2자 이상 적어야 [저장]이 됩니다. 사유는 최대 120자입니다.
  2. 저장하면 사유가 그 배정에 함께 기록됩니다. 막대에 마우스를 올리면 다시 볼 수 있고, 4-19의 작업 기록에도 "겹침 예외: 사유"로 남습니다.
  3. 사유가 적힌 겹침은 상대 배정 쪽에서도 예외로 인정됩니다. 두 배정 중 한쪽에만 사유를 적어도 양쪽의 경고가 안내(i)로 바뀝니다.
  4. 이미 겹친 채로 저장돼 있던 예전 배정은 지워지지 않고, 사유 없는 충돌로 계속 표시되어 정리하도록 알려 줍니다. 사람과 기간을 바꾸지 않는 수정(메모 등)이나 기간을 줄이는 수정은 막히지 않습니다.
  5. 겹침이 없어지도록 기간을 바꾸면 저장된 사유도 함께 비워집니다.
서버에서 거절될 때는 "다른 프로젝트(사이트가 다르거나 같은 프로젝트)와 일정이 겹쳐 배정할 수 없습니다" 또는 "일정이 겹치는 배정은 사유를 적어야 저장할 수 있습니다" 문구가 나옵니다.

4-19. 작업 기록

누가 언제 무엇을 바꿨는지를 출장자 관리 화면 오른쪽 위에서 확인합니다. 기록은 배정·인원·외부 일정·부서 특이사항의 추가·수정·삭제마다 서버가 자동으로 남기므로 별도로 입력할 것이 없습니다.

  1. 마지막 작업 카드: 일 단위/주 단위, 종합 엑셀, 새로고침 버튼 바로 아래에 같은 폭으로 있으며 가장 최근 작업의 사용자, 경과 시간, 내용(예: 인원 수정 · 홍길동)이 한 줄로 보입니다. 아직 기록이 없으면 "아직 기록된 작업이 없습니다"가 나옵니다.
  2. 카드를 누르면 타임라인이 아래로 펼쳐집니다. 날짜(오늘·어제·날짜)별로 묶여 있고 한 줄에 시각 · 종류(배정/인원/외부 일정/특이사항 + 추가/수정/삭제) · 사용자 · 내용과 프로젝트·부서가 나옵니다. 줄 왼쪽 색 막대는 추가(초록)·수정(파랑)·삭제(빨강)입니다.
  3. 처음에는 최근 5건이 보이고, 아래로 스크롤하면 더 오래된 기록을 볼 수 있습니다. 위쪽 선택 상자로 종류별로 걸러 볼 수 있습니다.
  4. 기록은 최근 100건만 보관됩니다. 새 기록이 쌓이면 가장 오래된 것부터 자동으로 지워지므로, 오래 보관해야 하는 내용은 따로 남겨 두세요.
  5. 한 줄에 다 안 들어가는 내용은 …로 줄여 보이며, 줄에 마우스를 올리면 전체 내용이 보입니다. 카드 밖을 누르거나 Esc 키를 누르면 닫힙니다.
  6. 기록은 조회 권한이 있는 사용자(관리자·Grade3·Grade2.5·Grade2)에게 보이고, 누구도 고치거나 지울 수 없습니다. 프로젝트를 삭제하면 그 프로젝트의 배정 삭제가 각각 기록됩니다.

9. 문제 해결

9-1. 로그인과 화면 표시

증상확인하고 해결하는 방법
로그인 직후 "권한 확인 중… 계정 정보를 불러오지 못했습니다"가 나옴서버 시계 차이로 잠깐 생기는 현상입니다. 안내 창의 [다시 시도]를 누르면 대부분 해결됩니다.
로그인이 안 됨회사 이메일(@twgroup.co.kr)과 비밀번호를 확인하고, 모르면 [비밀번호 재설정]을 씁니다. 관리자가 계정을 비활성화한 경우에도 로그인이 막힙니다.
화면이 최신 내용으로 바뀌지 않음사용자 메뉴의 [캐시 새로고침]을 누릅니다. 새 버전이 나오면 알림이 뜨니 안내에 따라 새로고침하세요.
버튼이 흐리거나 눌러도 안내 창이 뜸권한이 없는 기능입니다. 필요하면 시스템 관리자에게 권한 변경을 요청하세요.
화면이 좁아서 옆으로 스크롤됨머리말 영역에 최소 너비가 있어 작은 화면에서는 가로 스크롤이 생깁니다. PC 또는 태블릿 가로 화면에서 사용하세요.
태블릿에서 앱처럼 쓰고 싶음브라우저의 [홈 화면에 추가]를 쓰면 앱 아이콘으로 열 수 있습니다.
9. 문제 해결

9-2. 엑셀 붙여넣기·파일 첨부

증상확인하고 해결하는 방법
파일을 첨부했는데 열리지 않음DRM 보안 문서는 첨부가 안 될 수 있습니다. 엑셀에서 표를 복사해 점선 칸에 Ctrl+V 하세요(1-8).
Ctrl+V 해도 아무 일도 없음점선 칸을 먼저 한 번 눌러 커서를 두고 붙여넣거나 마우스 오른쪽 → 붙여넣기를 씁니다. 엑셀 셀(표)을 복사했는지 확인합니다.
칸이 비활성이고 이유가 적혀 있음프로젝트 미선택·권한 없음 같은 안내입니다. 안내대로 조건을 맞춥니다.
견적서 검증에서 합계가 맞지 않는다고 나옴수량×단가=금액, 상세 블록 합계=총계가 맞는지 엑셀 원본을 확인합니다. 시트마다 따로(견적서 시트, 상세 리스트 시트) 붙여넣었는지도 확인합니다.
팀원 붙여넣기에서 "퇴사 후보"가 많이 나옴표에 없는 재직 인원이 후보로 나온 것입니다. 기본 체크가 해제되어 있으니 퇴사시킬 사람만 체크하세요.
9. 문제 해결

9-3. 출장자·공수 관련

증상확인하고 해결하는 방법
프로젝트가 출장자 관리에 안 보임프로젝트 일정에 등록되어 있는지, 종료일이 오늘보다 앞서 숨겨진 것은 아닌지(프로젝트 선택의 "완료 시점이 지난 프로젝트도 보기") 확인합니다.
부서가 "공수 없음"이고 칸이 없음프로젝트에 해당 부서 계획 공수가 없는 것입니다. 마스터 스케줄을 다시 등록하거나 프로젝트 수정의 [부서별 공수 직접 등록](2-11)으로 적습니다. 직접 인원을 넣으려면 [+ 출장자]를 씁니다.
[부서별 공수 직접 등록]이 안내 문구만 나옴그 프로젝트에 Master Schedule 공수가 이미 있기 때문입니다. 마스터 공수가 우선이며, 직접 등록은 마스터 공수가 없는 프로젝트에서만 씁니다.
직접 등록 칸이 아예 안 보임프로젝트 정보를 모두 수정할 수 있는 관리자·Grade3 권한에서만 보입니다.
후보 목록에 사람이 안 나옴그 부서의 재직 인원만 나옵니다. 팀원 관리에 등록되어 있는지, 퇴사 처리되어 있지 않은지 확인합니다. PM 자리는 기구 인원도 나옵니다.
저장할 때 "경고가 있는 배정입니다" 확인 창이 뜸B1 비자가 없는 경우 등 일정 겹침 외의 경고입니다. 의도한 배정이면 [그래도 저장]을 누릅니다. 일정이 겹치는 경우는 이 창이 아니라 4-18의 규칙(차단 또는 사유 입력)이 적용됩니다.
후보 목록에서 사람이 "배정 불가"로 나오고 선택이 안 됨그 기간에 사이트가 다른 프로젝트나 같은 프로젝트에 이미 배정돼 있습니다. 기간을 나누거나 다른 사람을 고르고, 같은 프로젝트라면 기존 배정을 수정하세요(4-18).
"겹침 · 사유 필요"가 나오고 저장이 안 됨창 아래 "겹침 사유" 칸에 이유를 2자 이상 적으면 저장됩니다. 같은 사이트의 다른 프로젝트나 부재·외부 일정과 겹친 경우입니다.
"일정이 겹치는 배정은 사유를 적어야 저장할 수 있습니다" 오류사유가 비어 있는 상태로 서버에 저장하려 한 것입니다. 사유를 적고 다시 저장합니다.
작업 기록 카드가 보이지 않음새로고침(Ctrl+F5) 후에도 안 보이면 관리자에게 문의하세요. 기록은 최근 100건만 보관되며, 도입 이전의 작업은 기록되어 있지 않습니다.
[종합 엑셀]을 눌렀더니 권한 안내가 나옴종합 엑셀은 관리자·Grade3·Grade2.5만 내려받을 수 있습니다. Grade2는 보기 전용입니다.
엑셀에서 합계가 안 바뀜왼쪽 가장자리 A열의 H·M·S·T 표시를 지웠거나, 프로젝트 블록을 "PJT 별 취합 공수" 아래에 붙인 경우입니다. 표시를 되살리고 블록은 취합 줄 위에 붙이세요.
"비자 없음" 경고미국 사이트(HSBMA·SKBA·SKOT) 프로젝트에 B1 비자가 없는 사람을 넣은 경우입니다. 팀원 정보에서 B1 보유를 확인·수정합니다.
배정 기록이 있어 삭제가 안 되는 사람[퇴사]로 처리하세요. 후보에서 빠지고 기록은 유지됩니다.
"내 부서가 아닙니다" 확인 창팀장 계정에서 다른 부서를 수정하려 할 때의 확인 창입니다. 의도한 수정이면 [그래도 수정], 아니면 취소합니다.
실투입 공수가 비교분석에 안 나옴공사일보가 등록되어야 반영됩니다(3-7, 6장). 공사일보를 등록하고 [일보 새로고침]을 누릅니다.
